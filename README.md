# V60 搬送用 酸素ボンベ残時間計算

看護師・臨床工学技士・医師向けの、NPPV患者他院搬送時の簡易推定補助ツールです。メーカー公式計算機能ではありません。患者情報入力・外部API・入力値送信はありません。計算とチェック状態はメモリ内のみで保持し、再読込でリセットします。設定変更後は古い結果を消し、再計算を求めます。

## 開発環境・起動

Node.js 22.12以上（検証環境24.19）、npm、React 19、TypeScript、Vite。ロックファイルを使用してください。

```sh
npm ci
npm run dev
npm test
npm run build
npm run preview
npm run test:e2e
```

E2EにはChromiumが必要です。システムの `/usr/bin/chromium` がない場合は `npx playwright install chromium` で導入してください。

`dev` は開発用、`preview` はビルドした静的サイトの検証用です。配布時は `dist/` をHTTPSの静的ホスティングへ配置します。アプリ専用バックエンドは不要です。HTMLをfile://で直接開く運用は対象外です。

## 計算式（簡易推定式）

- 使用可能酸素量 = ボンベ容量 × max(0, 現在圧 − 安全残圧) ÷ 満充填圧
- 簡易総流量 = MinVent + Leak + 回路補正流量
- FiO₂比率 = FiO₂ (%) ÷ 100
- 酸素消費量 = 簡易総流量 × (FiO₂比率 − 0.21) ÷ 0.79
- 推定使用可能時間 = 使用可能酸素量 ÷ 酸素消費量
- 安全使用目安 = 推定使用可能時間 × 安全係数
- 余裕時間 = 安全使用目安 − 搬送予定時間

FiO₂21%は対象外表示とし、0除算しません。現在圧が安全残圧以下なら使用可能量と時間は0です。安全使用目安/搬送時間が1.5以上は緑、1以上1.5未満は黄、1未満は赤。判定には丸め前の値、表示には四捨五入した値を使用します。負の余裕時間は絶対値を「不足時間」と表示します。極端な入力による非有限の計算結果は拒否します。

## 初期値・変更

通常入力は空欄です。ボンベ容量500 L、満充填圧14.7 MPa、安全残圧1 MPa、回路補正5 L/min、安全係数80%。「詳細設定」で変更し、個別または全設定を初期値へ戻せます。安全係数は50～100%。変更は端末のメモリ内のみで、再読込時に初期値へ戻ります。

計算式は `src/utils/oxygenCalculation.ts`、装置モデルと初期設定は `src/config/defaults.ts`、型は `src/types/index.ts` に分離しています。式変更時はユニットテストと医療上の根拠・注意表示を再検討してください。将来の装置別モデルは設定オブジェクトと計算モジュールを追加する構成を想定しています。複数ボンベ・必要本数逆算は未実装です。

デモ条件：12 MPa / FiO₂40% / MinVent10 / Leak30 / 搬送30分。指定式による推定時間は約35分、安全使用目安は約28分、不足約2分です。仕様に記載された52分・42分はこの条件の計算値ではありません。

## PWA・オフライン

本番ビルドはアプリ資産をService Workerでキャッシュします。一度オンラインで読み込みを完了した後にオフライン使用ができます。HTTPSまたはlocalhostが必要です。対応ブラウザのメニューから「ホーム画面に追加」を選択してください。初回の完全オフライン起動はできません。キャッシュはアプリ資産のみで、患者情報・入力値を保存しません。更新後はオンラインで再読込し、新版の読み込みを確認してください。

## 医療安全上の注意

計算結果は簡易推定の参考値です。実際の酸素消費量は患者の呼吸状態、換気量、リーク量、FiO₂、換気設定、回路条件、装置動作などで変動します。Philips Respironics V60のメーカー公式酸素消費量計算式ではありません。回路補正5 L/minもメーカー公式値ではありません。

搬送時は十分な酸素残量・予備酸素を確保してください。本ツールのみで搬送可否を判断せず、医師の指示、院内搬送基準、機器の取扱説明書に従ってください。チェック完了も搬送可否を保証しません。臨床運用前に施設で仕様と運用を確認してください。
