独立した手計算参照（190 L、酸素必要150 L、空気必要90 L、電源必要30分）と一致。同一ボンベの区間残量引継ぎ、区間ごとの流量と遅延積算、交換条件、二重登録／二重割当遮断、緊急時留保の除外、切替前不足の検出を確認。

未入力・ゼロ・負値・非数値・非有限値・境界値・演算オーバーフロー・巨大有限値の表示、FiO₂％と小数、MPaと気道内圧単位、公称量と容器内容積、調査中／検証中／停止中／期限切れ／範囲外の臨床遮断、未知の必須資源での総合保留、保留中の既知不足表示、デモ分離、旧結果破棄を検証。

ブラウザでは操作・ラベル、8機種選択、Airvo入力切替、院外保留、入力変更時の結果とチェックリセット、再読込消去、320/375/768/1280pxの横スクロールなし、localStorage/sessionStorageを使用しないこと、Service Worker未登録、NaN/Infinityを表示しないことを確認。初回の機種selectのアクセス可能名を修正後に全試験通過。docs/demo-result.pngは架空デモ結果画面。

PWA・オフライン機能は実装しないためオフライン期限／停止キャッシュ機能の試験は対象外。旧版のService Workerが存在する端末への移行検証は未実施。本テストは新しいブラウザコンテキストを使用。
